# TrackPad – LeetCode Progress Tracker

TrackPad is a lightweight application built with **Streamlit** that helps track solved **LeetCode problems** and monitor coding practice progress. The tool provides a simple interface to record solved problems and view progress, helping users stay consistent while preparing for coding interviews.

---

## Overview

Preparing for technical interviews often requires solving a large number of coding problems on platforms like LeetCode. However, manually tracking solved problems and monitoring progress across different topics can be difficult.

TrackPad provides a simple solution by offering a dashboard that allows users to maintain a record of solved problems and track their progress in a structured way.

---

## Features

- Track solved LeetCode problems
- Record problem details and difficulty level
- View the total number of problems solved
- Simple and interactive interface using Streamlit
- Lightweight and easy to run locally

---

## Tech Stack

- **Python**
- **Streamlit**

---

## Architecture

```
User Input (Solved Problems)
        ↓
Data Storage / Tracking
        ↓
Streamlit Application
        ↓
Progress Display
```

---

## Installation

Clone the repository:

```bash
git clone https://github.com/thithikshajp-dot/TrackPad.git
cd TrackPad
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```

---

## Usage

1. Start the Streamlit application.
2. Add the LeetCode problems you have solved.
3. Track your progress and maintain consistency in coding practice.
